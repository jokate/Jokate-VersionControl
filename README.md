# Jokate-VersionControl

Unreal Engine 애셋 전용 로컬 버전관리 — 원격·결제 없이 `Content/` 의 `.uasset`/`.umap` 을 스냅샷하고 되돌린다.

- 애셋 단위 가시성: 클래스·의존성·썸네일을 읽어 "뭐가 바뀌었는지" 를 애셋으로 보여준다
- 저장하면 자동 스냅샷: 에디터에서 저장한 것을 감지해 알아서 찍는다
- 골라서 올리고 골라서 되돌리기: 선택한 애셋만 스냅샷·롤백
- 되돌리기는 항상 되돌릴 수 있다: 적용 전 안전 스냅샷 + 10초 실행 취소
- 에디터 안 우클릭 메뉴: 콘텐츠 브라우저에서 바로 올리기·되돌리기
- 리세이브 noise 접기, DataTable 값 diff

## 요구 사항

- Windows
- Python 3.11 이상, 표준 라이브러리만 사용 (pip 설치 없음)
- UE 5.x 에디터의 Python 플러그인 — 에디터 연동(우클릭 메뉴·롤백 중 리로드)을 쓸 때만

## 빠른 시작

```
git clone https://github.com/jokate/Jokate-VersionControl
```

1. `start.bat` 을 더블클릭한다
2. 처음이면 `.uproject` 선택 창이 뜬다 (선택한 프로젝트는 기억된다)
3. 브라우저에 타임라인이 열린다 (`http://127.0.0.1:8765/`)

에디터 연동까지 쓰려면 `bridge-install.bat` 을 한 번 실행하고 에디터를 재시작한다.

## 개념

### 두 등급

| 등급 | 대상 | 동작 |
|---|---|---|
| `vendor` | Paragon, 마켓 팩 등 가져온 것 | 동결. 해시 검증만. 히스토리에 안 섞임 |
| `authored` | 직접 만든 것 | 저장 즉시 자동 스냅샷. 히스토리·롤백 대상 |

폴더 규칙은 `<project>/.jokate/config.toml` 에 적는다.

```toml
[project]
content = "Content"

[tiers]
vendor = ["Paragon*", "SwordAnimsetPro"]
ignore = ["Developers", "Collections"]
```

### 확정 버전과 작업 중 기록

git/svn 처럼 **확정한 것만 이력으로 남는다.**

- **확정 버전** — 내가 메시지를 붙여 확정(`confirm`)한 것. 영구 이력이라 자동으로 지워지지 않는다
- **작업 중 기록** — 저장 감지 자동 저장, 되돌리기 안전 스냅샷 등. **확정하거나 변경을 버리면 사라진다**
- **확정 안 된 변경** — 마지막 확정 상태 대비 디스크의 차이 (작업 중 기록이 아무리 쌓여도 비지 않는다)
- **변경 버리기** — 확정 안 된 변경을 버리고 마지막 확정 상태로 되돌리기. 되돌리기 직전 상태 하나만 '실행 취소 지점'으로 남는다

### 스냅샷 종류

- `label` — 이름을 붙여 확정한 것
- `auto` — 저장 감지로 자동으로 찍힌 것(작업 중 기록)
- 리세이브만 — 내용은 그대로고 헤더만 바뀐 스냅샷. 타임라인에서 흐리게 표시되고 기본으로 접힌다

## 평소 흐름

- 에디터에서 저장하면 잠시 뒤 `auto` 스냅샷이 찍힌다 — 이건 **작업 중 기록**일 뿐, 확정한 것이 아니다
- '확정 안 된 변경' 카드는 **마지막 확정 상태 대비** 차이라서 작업 중 기록이 아무리 쌓여도 비지 않는다
- 확정할 때는 그 카드 아래에 메시지를 쓰고 큰 버튼을 누른다 — 선택이 없으면 '전부 확정', 애셋을 고르면 '선택한 n개 확정'
- **확정하면 그 전의 작업 중 기록은 지워지고 확정 버전 하나만 남는다** — 작업이 길어져도 이력이 끝없이 늘지 않는다
- 확정 안 된 변경을 되돌리려면 같은 카드의 '변경 버리기'(웹) 또는 `discard`(CLI)
- 카드 제목 옆에 기준이 보인다 — `마지막 확정 #N 이후`

### 웹 UI 조작

- 왼쪽 열은 git 클라이언트처럼 위아래로 나뉜다: **확정 안 된 변경** → **작업 중 기록** 서랍(기본 접힘, '자동 저장 n · 되돌리기 n', 확정하면 지워진다) → **확정 이력**(확정 버전만)
- 확정 안 된 변경: 클릭 선택 · Shift 범위 · Ctrl 추가 · Ctrl+A 전체 · 우클릭 메뉴('선택한 것만 확정', '전부 확정', '선택한 변경 버리기')
- 확정 이력: 세로 레일에 확정 버전만 쌓인다. 확정한 버전에는 '확정 n개' 표시, 새로 들어온 버전은 잠깐 테두리로 알려준다. 우클릭 → 묶기·되돌리기
- 작업 중 기록 서랍: 항목 클릭 = 상세 보기, 우클릭 = '이 시점으로 되돌리기'
- 세 영역 모두 5초마다 알아서 갱신된다(탭을 다른 데 두면 쉰다)
- 애셋 이름·클래스·메시지로 검색(확정 이력 헤더 입력창, `/` 키)
- 경계선 드래그·카드 접기·보기 옵션은 브라우저에 기억된다(`jokate.layout.v1`)

## 되돌리기

| 하고 싶은 것 | 방법 |
|---|---|
| 방금 저장한 것 취소(변경 버리기) | '확정 안 된 변경' 에서 선택 → '변경 버리기' 버튼 또는 우클릭 → '선택한 변경 버리기' (기준은 항상 마지막 확정 상태) |
| 애셋을 과거 확정 버전으로 | 버전 상세에서 선택 → 우클릭 → '선택한 애셋을 이 버전으로 되돌리기' (결과는 '확정 안 된 변경'으로 남고, 확정을 눌러야 새 확정 버전) |
| 썸네일 보고 버전 고르기 | 애셋 버전 히스토리 카드 우클릭 → '이 버전으로 되돌리기' |
| 버전 전체 | 확정 이력 우클릭 → '이 버전 전체로 되돌리기' |

변경 버리기를 하면 버리기 직전 상태 하나만 '실행 취소 지점'으로 남고 나머지 작업 중 기록은 정리된다(그 상태가 이미 확정 버전 트리에 들어 있으면 그 확정 버전이 실행 취소 지점이 된다). 작업 중 기록으로 남은 지점은 다음 확정이나 다음 버리기 때 사라진다.

되돌리기는 항상 확인 모달(바뀔 목록·참조 경고)을 먼저 띄운다. 적용 직전 상태를 자동으로 남기는데, 이때 **되돌리는 애셋만** 기록하므로 다른 애셋의 확정 안 된 변경은 그대로 유지된다. 적용 뒤 토스트의 '실행 취소' 버튼이 10초간 남는다. 에디터에서 아직 저장하지 않은 애셋이 대상이면 중단하고 물어본다(원하면 버리고 진행).

에디터가 켜져 있으면 되돌릴 애셋의 파일을 에디터가 잠그고 있으므로, 적용 직전에 브릿지로 그 패키지들을 잠깐 언로드(release)해 잠금을 푼 뒤 파일을 쓰고 다시 리로드한다. 그래도 잠긴 파일이 있으면 **아무 파일도 바꾸지 않고** 잠긴 목록을 보여준다 — 에디터에서 그 애셋의 편집 창을 닫고 다시 시도하면 된다.

## 에디터 안에서

`bridge-install` 후 재시작하면 콘텐츠 브라우저 애셋 우클릭에 `Jokate` 메뉴가 생긴다.

- 선택한 애셋 확정
- 선택한 애셋 변경 버리기(마지막 확정 상태로)
- 히스토리 열기(웹)
- 확정 안 된 변경 보기(웹)

툴(Tools) 메뉴의 Jokate 섹션에는 '지금 전부 확정'(메시지는 '에디터에서 확정')·브릿지 켜기/끄기·데몬 시작·타임라인 열기·상태 보기가 있다.

에디터를 켜면 데몬이 자동으로 실행된다(꺼져 있을 때만). 데몬이 돌 때는 윈도우 트레이 아이콘에서 타임라인 열기·지금 스냅샷·일시정지·종료를 할 수 있다.

## 에디터에서 리비전 컨트롤로 쓰기

Jokate 를 언리얼의 **리비전 컨트롤(Revision Control)** 프로바이더로 붙이면 콘텐츠 브라우저 애셋에 상태 아이콘(확정 안 된 변경 / 새 애셋 / 삭제됨)이 뜬다.

1. 설치: `python -m jokate plugin-install <project>` — `ue-plugin/JokateSourceControl` 이 `<project>/Plugins/JokateSourceControl` 로 복사된다(기존 `Binaries`·`Intermediate` 는 유지).
2. 빌드: 에디터를 닫고 `.uproject` 우클릭 > Generate project files 후 빌드하거나, 에디터 실행 시 "다시 빌드하시겠습니까" 창에서 예.
3. 선택: 에디터 우하단(또는 상단) **리비전 컨트롤 > 리비전 컨트롤 연결**에서 프로바이더를 `Jokate` 로 고르고 포트(기본 8765)를 확인한다. 데몬이 꺼져 있으면 `start.bat` 또는 툴 메뉴 Jokate > 데몬 시작.
4. 웹과 함께: 확정·되돌리기·히스토리는 지금은 타임라인 웹에서 한다(설정 패널의 '타임라인 열기' 버튼). 플러그인은 상태 표시와 연결 확인만 담당한다.

포트는 `<project>/.jokate/daemon.json` 이 있으면 그 값을 우선 쓰고, 없으면 `SourceControlSettings.ini` 의 `[JokateSourceControl.JokateSourceControlSettings] Port` 를 쓴다.

## 레이아웃 조정

웹 UI 는 자유롭게 크기를 바꿀 수 있다. 왼쪽 열과 상세 사이, 확정 안 된 변경과 확정 이력 사이, 상세 안 변경 애셋 표와 버전 히스토리 사이에 각각 드래그 경계선이 있다(더블클릭하면 그 경계선만 기본값으로, 경계선에 포커스를 두고 화살표 키로도 조절). 통계 바·확정 안 된 변경·작업 중 기록 서랍·확정 이력·버전 히스토리는 헤더의 ▾/▸ 로 접을 수 있고(작업 중 기록은 기본 접힘), 통계 바를 접으면 한 줄 요약이 남는다. 상세 카드 헤더의 ⤢ 또는 `f` 키로 왼쪽 열을 숨기고 상세를 전체 폭으로 볼 수 있으며 다시 누르거나 Esc 로 복귀한다. 헤더의 '보기' 버튼에서는 목록 밀도, 버전 카드 썸네일 크기, 행 썸네일 표시 여부를 바꾸고 '레이아웃 초기화'로 모두 되돌릴 수 있다. 이 값들은 브라우저 `localStorage` 에 저장되어 새로고침 후에도 유지되며, 화면이 900px 이하로 좁아지면 세로 경계선과 크게 보기는 숨겨지고 단일 열로 표시된다.

## 더 깊게 보기

- 내용 변경: 수정된 DataTable 행을 클릭하면 값 변경 표가, DataAsset·커브·인풋 같은 일반 애셋은 속성 요약 표(키 · 이전값 → 새값)와 접히는 원문 diff 가 뜬다. 에디터가 켜져 있을 때 찍힌 스냅샷부터 기록된다. 대상 클래스는 `[meta] text_classes` 로 조정한다
- 참조 변화: 수정·이동된 애셋 행의 '참조 +2 −1' 필을 누르면(또는 올려두면) 새로 생긴/사라진 참조 애셋 목록이 펼쳐진다. 내용 diff 가 없는 DataAsset 도 무엇을 가리키게 됐는지 보인다. vendor 폴더 참조는 `vendor`, 프로젝트에 없는 대상은 `없는 애셋` 표시. CLI `show`/`status` 출력에도 `    + /Game/...` 줄로 같이 나온다
- UE 에서 diff 열기: 블루프린트처럼 우리 UI 로 못 보는 애셋은 언리얼 에디터 diff 창으로 두 버전을 나란히 연다
- 자동 스냅샷 묶기·보관기간 정리: 연속된 auto 스냅샷을 하나로 묶고(`squash`), 오래된 auto 를 정리한다(`prune`, 라벨은 안 지움)

## 배치 파일

경로를 타이핑하지 않는다. 처음 한 번 `.uproject` 를 고르면 기억한다.

| 파일 | 하는 일 |
|---|---|
| `start.bat` | 데몬(웹 UI + 자동 스냅샷)을 창 없이 띄우고 브라우저 열기 |
| `stop.bat` | 돌고 있는 데몬 종료 |
| `snap.bat` | 올리지 않은 변경을 보여주고 메시지를 받아 라벨 스냅샷 |
| `bridge-install.bat` | 에디터 브릿지 + Jokate 우클릭 메뉴 설치 |
| `change-project.bat` | 기억한 프로젝트를 지우고 다시 선택 |

## CLI

```
python -m jokate <명령> <project> [옵션]
```

| 명령 | 설명 |
|---|---|
| `init` | `.jokate/config.toml` 생성 |
| `scan` | Content 스캔 (`--hash-vendor`) |
| `inspect` | 패키지 파일 하나 뜯어보기 (`--thumb`) |
| `table` | 애셋 표 출력 (`--tier`, `--cls`) |
| `snap` | `-m` 있으면 `confirm` 과 동일, 없으면 작업 중 기록(자동 스냅샷) (`--force`, `--only`) |
| `confirm` | 고른 변경을 확정 — 확정 버전 하나를 남기고 그 전의 작업 중 기록을 정리 (`-m`, `--only rel ...`) |
| `upload` | `confirm` 의 옛 이름 |
| `status` | 마지막 확정 상태 대비 확정 안 된 변경 |
| `discard` | 고른 애셋의 확정 안 된 변경 버리기 (`--asset`, `--apply`. 기본 드라이런) |
| `revert` | `discard` 의 옛 이름 |
| `log` | 확정 버전 목록 (`--all` 이면 작업 중 기록도 들여써서 함께) |
| `show` | 스냅샷 하나의 A/M/R/D |
| `restore` | 롤백 (`--asset`, `--apply`, `--discard-dirty`. 기본 드라이런) |
| `uediff` | 두 버전을 UE diff 창으로 열기 (`<rel> <id_a> [id_b]`). 에디터가 켜져 있으면 그 에디터 안에서만 열고 두 번째 에디터는 띄우지 않는다(브릿지가 꺼져 있으면 안내 후 exit 2) |
| `squash` | `<from_id> <to_id>` 사슬을 하나로 묶기 (`-m`, `--include-labels`) |
| `prune` | 오래된 auto 스냅샷 정리 (`--days`, `--keep`, `--dry-run`) |
| `gc` | 참조 없는 객체 파일 삭제 (`--dry-run`) |
| `bridge-install` | 에디터 브릿지 설치 |
| `bridge-status` | 브릿지 heartbeat 상태 |
| `watch` | 저장 감지 자동 스냅샷 (`--interval`, `--debounce`) |
| `serve` | 타임라인 웹 UI (`--port`) |
| `daemon` | 웹 UI + 자동 스냅샷을 창 없이 (`--port`, `--interval`, `--debounce`) |
| `daemon-stop` | 실행 중인 데몬 종료 |

## 설정

`<project>/.jokate/config.toml`

```toml
[project]
content = "Content"          # 추적 루트 (프로젝트 기준 상대경로)

[tiers]
vendor = ["Paragon*"]        # 동결 등급 (Content 기준 glob)
ignore = ["Developers", "Collections"]

[web]
port = 8765                  # 웹 UI 포트

[meta]
# '내용 변경' 을 T3D 텍스트로 기록할 클래스 (fnmatch). DataTable 은 항상 표로 기록된다
# Blueprint·머티리얼·텍스처·메시·애니메이션·레벨은 기본 제외 — 직접 써 넣으면 허용
text_classes = ["*DataAsset", "CurveFloat", "CurveTable", "InputAction", "InputMappingContext", "YS*"]

[retention]
auto_days = 14               # 이보다 오래된 auto 스냅샷을 정리 대상으로
keep_last_auto = 30          # 최신 auto 는 이만큼 보존 (0 이면 정리 안 함)

[editor]
exe = ""                     # UnrealEditor.exe 경로 (비우면 자동 탐색)
autostart = true             # 에디터를 켜면 데몬 자동 실행

[daemon]
tray = true                  # 트레이 아이콘
```

## 데이터 위치와 백업

모든 히스토리는 `<project>/.jokate/` 하나에 들어 있다(설정·SQLite 인덱스·객체 파일·로그). 이 폴더를 지우면 히스토리가 사라지고, 통째로 복사하면 그대로 옮겨진다. 프로젝트를 git 으로도 관리한다면 `.jokate/` 를 프로젝트의 `.gitignore` 에 넣는 편이 보통 낫다(로컬 히스토리라 용량이 크다). 팀에 공유하고 싶다면 빼도 되지만 저장소가 빠르게 커진다.

## 한계와 주의

- 텍스트 diff 가 아니다. 애셋 단위 스냅샷이라 "이 함수가 바뀌었다" 같은 건 알려주지 않는다
- 큰 텍스처·맵을 자주 저장하면 저장소 용량이 늘어난다 (`prune`/`gc` 로 정리)
- `vendor` 등급은 스냅샷에 포함되지 않는다
- 에디터 연동은 UE 5.7 기준으로 만들었다. 다른 버전은 확인이 필요하다
- 한 PC 에서 여러 프로젝트를 동시에 쓰려면 프로젝트마다 `[web] port` 를 다르게 준다
