22d단계: UE 플러그인 JokateSourceControl 마무리(다듬기 + 문서). 현재 상태: ue-plugin/JokateSourceControl 은 UE 5.7.4 에서 빌드되고 실제 에디터에서 검증됐다 — 프로바이더 연결, 상태 조회(authored=추적, vendor=추적 안 함), 수정 감지, Revert(POST /api/discard), Submit(POST /api/confirm, 약 1초), 데몬 재시작 뒤 자동 재연결(Tick 에서 5초마다 TryReconnect)이 모두 동작한다. 너는 C++ 를 컴파일해 볼 수 없으니, 지금 컴파일되는 기존 코드의 include·형식·패턴을 그대로 따르고, 확신이 없는 엔진 API 는 쓰지 말 것(첨부 헤더에 있는 것만). 할 일: (1) 재연결 핑의 로그 소음 제거 — 데몬이 꺼져 있는 동안 TryReconnect 가 5초마다 FJokateHttp 의 Warning '요청 실패' 를 찍는다. FJokateHttp::Request/GetJson 에 bQuiet(기본 false) 인자를 추가해 true 면 실패 로그를 Verbose 로 낮추고, CheckConnection 에 bQuiet 를 전달할 수 있게 해 TryReconnect 에서만 조용히 부른다. 또 연속 실패 시 간격을 5초 → 10초 → 30초(최대)로 늘리고 성공하면 5초로 되돌린다. 끊긴 순간 한 번만 Warning 'Jokate 데몬과 연결이 끊겼습니다. 다시 연결을 시도합니다.' 를 남긴다. (2) 에디터 메뉴 '타임라인 열기' — 브릿지(파이썬)가 없어도 쓸 수 있게 플러그인 모듈이 ToolMenus 로 LevelEditor.MainMenu.Tools 에 섹션 'Jokate' 와 항목 두 개를 등록한다: '타임라인 열기'(FPlatformProcess::LaunchURL 로 http://127.0.0.1:<port>/), '상태 새로 고침'(프로바이더가 Jokate 일 때 전체 UpdateStatus 를 비동기로 실행). 등록은 UToolMenus::RegisterStartupCallback, 해제는 ShutdownModule 에서 UToolMenus::UnRegisterStartupCallback + UnregisterOwner. 파이썬 브릿지도 같은 Tools 메뉴에 'Jokate' 항목을 만들므로 섹션 이름은 'JokateSourceControl' 로, 라벨은 'Jokate 리비전 컨트롤' 로 구분한다. Build.cs 에 ToolMenus 의존을 추가. 첨부된 ToolMenus.h 의 시그니처를 확인하고, 엔진의 다른 플러그인이 쓰는 표준 패턴(FToolMenuOwnerScoped, UToolMenus::Get()->ExtendMenu, Section.AddMenuEntry(Name, Label, ToolTip, FSlateIcon(), FUIAction(FExecuteAction::CreateLambda(...))))만 사용. (3) GetStatusText 다듬기 — 연결 안 됨일 때 마지막 오류(LastError)와 안내 '(start.bat 을 실행하면 자동으로 다시 연결됩니다)' 를 덧붙인다. 확정 안 된 변경 수(GetNumLocalChanges)도 한 줄로.
