22b단계: 언리얼 에디터 C++ 플러그인 'JokateSourceControl' 뼈대 — Jokate 를 언리얼의 리비전 컨트롤(Revision Control / Source Control) 프로바이더로 등록한다. 대상 엔진: UE 5.7 (설치형 빌드, 엔진 경로 C:/Unreal/UE_5.7). 너는 C++ 를 컴파일해 볼 수 없다 — 그래서 엔진에 들어 있는 Git 프로바이더를 '정답 예제'로 삼아 같은 구조·같은 시그니처로 작성해야 한다. 첨부 파일(또는 C:/Unreal/UE_5.7/Engine/Plugins/Developer/GitSourceControl/Source/GitSourceControl/Private/*.h,*.cpp, GitSourceControl.Build.cs, GitSourceControl.uplugin, 그리고 C:/Unreal/UE_5.7/Engine/Source/Developer/SourceControl/Public/ISourceControlProvider.h, ISourceControlState.h, ISourceControlRevision.h, SourceControlOperations.h)을 반드시 먼저 읽고, 순수 가상 함수 목록·인자·const·override 를 5.7 헤더 그대로 맞춰라. 헤더에 없는 함수를 override 하거나 있는 순수 가상 함수를 빠뜨리면 컴파일이 깨진다. Git 플러그인 소스는 Epic 저작물이므로 복사해 붙이지 말고 구조만 참고해 새로 작성한다. 위치: 이 저장소의 ue-plugin/JokateSourceControl/ (JokateSourceControl.uplugin, Resources/Icon128.png 는 생략 가능, Source/JokateSourceControl/JokateSourceControl.Build.cs, Private/*.h *.cpp). 구성: (1) .uplugin — Type Editor, LoadingPhase Default(Git 플러그인과 동일하게), EnabledByDefault true, Category 'Source Control', 설명 한국어·영어. (2) Build.cs — Git 플러그인의 의존 모듈을 기준으로 Core, CoreUObject, Slate, SlateCore, InputCore, EditorFramework/UnrealEd(필요한 것만), SourceControl, Projects, HTTP, Json, JsonUtilities, DeveloperSettings 중 실제로 쓰는 것만. (3) FJokateSourceControlModule — StartupModule 에서 IModularFeatures 에 'SourceControl' 피처로 프로바이더 등록, ShutdownModule 에서 Close + 해제. 설정(포트) 접근자. (4) FJokateSourceControlSettings — 포트(기본 8765)를 Git 플러그인처럼 SourceControlHelpers::GetSettingsIni() 의 섹션 'JokateSourceControl.JokateSourceControlSettings' 에 저장/로드. 프로젝트의 <ProjectDir>/.jokate/daemon.json 이 있으면 그 port 를 우선 사용. (5) FJokateHttp — 동기 HTTP 도우미: FHttpModule 로 요청을 만들고 SetDelegateThreadPolicy(EHttpRequestDelegateThreadPolicy::CompleteOnHttpThread) 로 완료 콜백을 HTTP 스레드에서 받게 한 뒤 FEvent 로 대기(타임아웃 기본 10초, 확정·버리기는 60초). 게임 스레드에서 호출돼도 데드락이 없어야 한다(콜백이 게임 스레드 틱을 기다리지 않게 하는 것이 핵심). GetJson(path)/PostJson(path, body) → (bOk, StatusCode, TSharedPtr<FJsonObject>, ErrorText). (6) FJokateSourceControlState : ISourceControlState — 파일 절대경로, 상태 enum(Unknown, Clean, Modified, Added, Deleted, Untracked, Missing), 타임스탬프, 히스토리(22c 에서 채움, 지금은 빈 배열). 5.7 헤더의 모든 순수 가상 함수 구현: 아이콘(GetIcon — 5.x 는 FSlateIcon, Git 플러그인이 쓰는 RevisionControlStyle 아이콘 이름을 참고해 Modified/Added/Deleted 에 대응), GetDisplayName/GetDisplayTooltip(한국어: '확정 안 된 변경', '새 애셋(확정 전)', '삭제됨(확정 전)', '확정됨', '추적 안 함'), IsSourceControlled(Untracked·Missing·Unknown 이 아니면 true), IsModified, IsAdded, IsDeleted, IsCurrent(true), CanCheckIn(Modified·Added·Deleted), CanCheckout(false), IsCheckedOut(false — 단 Git 플러그인이 '수정 가능' 판정을 어떻게 하는지 보고 CanEdit true), CanRevert(CanCheckIn 과 동일), CanAdd(false), CanDelete, IsUnknown, IsIgnored, IsConflicted(false) 등. (7) FJokateSourceControlProvider : ISourceControlProvider — Init(연결 확인: GET /api/ping 으로 root 가 이 프로젝트의 ProjectDir 와 같은지 비교해 bAvailable 설정), Close, GetName('Jokate'), GetStatusText(연결 상태·포트·마지막 확정 버전), IsEnabled, IsAvailable, GetState(파일 목록 → 캐시된 상태, EStateCacheUsage::ForceUpdate 면 UpdateStatus 실행), GetCachedStateByPredicate, 상태 변경 델리게이트 등록/해제, Execute(Connect·UpdateStatus 만 이번 단계에서 구현하고 나머지 operation 은 ECommandResult::Failed 가 아니라 '지원 안 함' 메시지와 함께 Failed — 22c 에서 구현), CanExecuteOperation, CanCancelOperation(false), CancelOperation, UsesLocalReadOnlyState(false), UsesChangelists(false), UsesUncontrolledChangelists(false), UsesCheckout(false), UsesFileRevisions(true), UsesSnapshots(false), AllowsDiffAgainstDepot(true), IsAtLatestRevision(true), GetNumLocalChanges(캐시에서 CanCheckIn 인 수), Tick(상태 변경 브로드캐스트), GetLabels(빈 배열), GetChangelists(빈 배열), MakeSettingsWidget(SOURCE_CONTROL_WITH_SLATE 가드: 포트 입력 + '타임라인 열기' 버튼(FPlatformProcess::LaunchURL) + 데몬이 안 떠 있을 때의 안내 문구 'start.bat 을 실행하거나 에디터 툴 메뉴 Jokate > 데몬 시작'), 그리고 5.7 헤더에 추가로 있는 순수 가상 함수 전부. 실행 모델은 단순하게: Git 플러그인의 워커/커맨드 큐 구조를 그대로 흉내 내지 말고, Execute 가 동기든 비동기든 'HTTP 호출 → 결과로 상태 캐시 갱신 → 완료 델리게이트 호출' 을 게임 스레드에서 안전하게 수행한다. 비동기(Asynchronous)일 때는 Async(EAsyncExecution::ThreadPool) 로 HTTP 를 돌리고 AsyncTask(ENamedThreads::GameThread) 로 캐시 갱신·델리게이트 호출을 되돌린다.
