17단계: 웹 UI 레이아웃을 사용자가 자유롭게 조정할 수 있게. 대상은 jokate/web_static/index.html 하나(서버 코드 변경 없음, vanilla JS, 프레임워크 금지). 현재: main 은 grid 380px | 1fr 고정, 왼쪽은 '현재 변경사항' 카드(max-height 46%)와 '타임라인' 카드, 오른쪽 '상세' 카드 안에 변경 애셋 표·내용 변경·버전 히스토리가 세로로 쌓인다. 900px 이하에서는 단일 열. 요구: (1) 드래그 경계선(splitter) 3개 — ① 왼쪽 열과 상세 사이 세로 경계선: 왼쪽 폭 260px~화면의 60% ② 왼쪽 열 안 변경사항 카드와 타임라인 카드 사이 가로 경계선: 변경사항 높이 80px~왼쪽 열의 75% ③ 상세 카드 안 '변경 애셋 표 영역'과 '버전 히스토리 영역' 사이 가로 경계선: 위쪽 영역이 자체 스크롤을 갖고 아래 히스토리 영역 높이를 조절(히스토리가 열려 있을 때만 표시). 경계선은 6px 히트 영역에 hover·드래그 중 accent 색, 커서 col-resize/row-resize, 드래그 중 텍스트 선택 방지와 iframe 없는 환경 기준 pointer 이벤트(setPointerCapture) 사용, 더블클릭하면 그 경계선만 기본값으로. 키보드 접근: 경계선에 tabindex 와 화살표 키로 16px 씩 조절. (2) 접기: 통계 바, 현재 변경사항, 타임라인, 버전 히스토리 각각의 헤더에 접기 토글(▾/▸). 접힌 카드는 헤더만 남고 남은 공간은 이웃이 차지. 통계 바를 접으면 헤더 아래 한 줄 요약('올릴 변경 n · 스냅샷 n · 저장소 x')으로. (3) 상세 크게 보기: 상세 카드 헤더의 ⤢ 버튼 또는 키 'f' 로 왼쪽 열을 숨기고 상세를 전체 폭으로, 다시 누르면 복귀. Esc 로도 복귀(단 메뉴·모달·선택 해제보다 우선순위 낮게). (4) 보기 옵션 메뉴(헤더의 '보기' 버튼 → 작은 팝오버): 목록 밀도 촘촘/보통/넉넉(행 패딩·글자 크기 CSS 변수), 버전 카드 썸네일 크기 작게 96 / 보통 156 / 크게 224, 행 썸네일 표시 on/off, '레이아웃 초기화' 버튼. (5) 저장: 모든 값(세 경계선 위치, 접힘 상태, 크게 보기 아님, 밀도, 썸네일 크기, 행 썸네일)을 localStorage 'jokate.layout.v1' 하나의 JSON 으로 저장하고 로드 시 복원, 값이 화면 크기에 안 맞으면 범위로 clamp, 창 resize 때도 clamp. 파싱 실패·구버전 값은 기본값으로. (6) 900px 이하 단일 열에서는 세로 경계선 ① 과 크게 보기를 끄고(숨김), 카드 접기와 보기 옵션은 그대로 동작. (7) 구현 지침: CSS 변수(--left-w, --changes-h, --hist-h, --row-pad, --thumb, --ver-thumb)로 제어하고 기존 디자인 토큰 재사용, opacity 0 에서 시작하는 CSS 애니메이션 금지, 드래그 중에는 transition 끄기. 기존 기능(다중 선택, 우클릭 메뉴, 검색, 리세이브 접기, 데몬 칩, 딥링크, 묶기, 정리, 내용 변경 표, UE diff, 실행 취소, 키보드 단축키 '/'·Ctrl+A·Esc)이 전부 그대로 동작해야 하며, 목록을 다시 그려도(loadStatus/select/showHistory) 레이아웃 값이 유지돼야 한다. 레이아웃 상태 계산은 순수 함수(clampLayout(state, viewport) 등)로 분리. (8) 검증용: tests/test_web_static.py 신설 — index.html 을 읽어 필수 요소 id/클래스(세 경계선, 접기 토글, 보기 메뉴, 초기화 버튼)와 localStorage 키 문자열이 존재하는지, <script> 본문을 node 가 있으면 'node --check' 로 문법 검사(없으면 skip)하는 가벼운 테스트. README 의 UI 관련 절에 '레이아웃 조정' 한 단락(README 가 이미 정리되어 있으면 그 구조를 유지하며 추가). 검증: uv run --no-project --with pytest pytest -q 전부 통과. 경로는 슬래시만. MNYS 에서 어떤 jokate 명령도 실행 금지. 편집은 Edit 도구로.
